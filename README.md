# Paper Template

This repo is intended to be a catchall starting template for paper-writing. 
It is intended to synthesize paper-writing advice from blog posts, articles, etc into a single base template. 
It currently uses the NeurIPS style.

See `paper_template.pdf` for the pdf version. Also see the comments in the tex files, which contain more distilled advice.

This repo takes inspiration from: 
- Jennifer Widom, Stanford - https://cs.stanford.edu/people/widom/paper-writing.html
- Andrej Karpathy, OpenAI / Tesla - https://karpathy.github.io/2016/09/07/phd/
- Jacob Steinhardt, Berkeley - https://bounded-regret.ghost.io/advice-for-authors/
